## Розділ 8. Обґрунтування вибору типу бази даних

Для реалізації інформаційної системи автоматизації бібліотеки обрано **об'єктно-реляційну СУБД PostgreSQL**. Даний вибір зумовлений необхідністю суворого дотримання цілісності даних та складною логічною структурою об'єктів моделювання.

### 8.1. Архітектурна відповідність моделі даних
Згідно з проєктом, система оперує великою кількістю пов'язаних сутностей. Реляційна модель PostgreSQL дозволяє реалізувати:
* **Нормалізація до 3NF**: Структура таблиць `users`, `books`, `book_items` та `loans` розроблена для мінімізації надмірності. Наприклад, поділ на `books` (загальна інформація) та `book_items` (конкретні примірники з `inventory_number`) дозволяє уникнути дублювання назв та авторів.
* **Цілісність посилань (Referential Integrity)**: Використання обмежень `FOREIGN KEY` гарантує, що запис у таблиці `loans` не може існувати без посилання на існуючого користувача та конкретний інвентарний номер книги.
* **Обробка транзакцій (ACID)**: У процесах видачі та повернення книг критично важливою є атомарність. PostgreSQL гарантує, що зміна статусу книги та створення запису про позику відбудуться як одна неподільна операція.

### 8.2. Програмна реалізація та продуктивність
* **Механізм pg-pool**: У коді бекенду (файл `db.js`) впроваджено пул з'єднань (`new Pool`), що дозволяє оптимізувати використання ресурсів при великій кількості одночасних запитів до каталогу.
* **SQL-оптимізація**: Система використовує складні JOIN-запити для формування звітності в реальному часі, що забезпечує швидку роботу модуля аналітики (статистика фонду та протермінованих видач).

```javascript
// Фрагмент коду: Підключення до PostgreSQL (db.js)
const { Pool } = require('pg');
const pool = new Pool({
  user: process.env.DB_USER,
  host: process.env.DB_HOST,
  database: process.env.DB_NAME,
  password: process.env.DB_PASSWORD,
  port: process.env.DB_PORT,
});

module.exports = {
  query: (text, params) => pool.query(text, params),
};
```

```javascript
// Встановлення зв'язків (1:N)
db.Book.hasMany(db.Copy, { foreignKey: 'book_id' });
db.Copy.belongsTo(db.Book, { foreignKey: 'book_id' });
db.User.hasMany(db.Circulation, { foreignKey: 'user_id' });
db.Circulation.belongsTo(db.User, { foreignKey: 'user_id' });
```
