## Розділ 11. Перспективи розвитку системи

На основі аналізу розробленого прототипу та його програмної реалізації (React + Express + PostgreSQL), визначено наступні стратегічні вектори модернізації.

### 11.1. Інтелектуалізація та автоматизація
* **Розширена аналітика**: Доопрацювання існуючого модуля статистики (`Chart.js`) для побудови прогнозних моделей попиту на літературу на основі історичних даних позик.
* **Автоматизація сповіщень**: Інтеграція з Telegram API або Email-сервісами для автоматичного розсилання нагадувань боржникам, що виявляються через існуючу функцію `overdue-check`.
* **Інтеграція за ISBN**: Підключення до Google Books API для автоматичного заповнення карток книг при їх додаванні в базу за штрих-кодом.

### 11.2. Технологічна трансформація
* **RFID-ідентифікація**: Заміна ручного введення `inventory_number` на зчитування RFID-міток, що дозволить реалізувати станції швидкого самообслуговування та автоматизовану інвентаризацію полиць.
* **Мобільний клієнт (PWA/Native)**: Створення мобільного додатку для читачів, що забезпечить швидкий доступ до електронного каталогу та можливість онлайн-резервування примірників.

### 11.3. Масштаб та надійність
* **Cloud Backup**: Впровадження автоматичного щоденного резервного копіювання бази даних у хмарне сховище.
* **Microservices**: Декомпозиція монолітного бекенду на окремі сервіси (сервіс користувачів, сервіс фонду, сервіс логів) для підвищення відмовостійкості системи.
