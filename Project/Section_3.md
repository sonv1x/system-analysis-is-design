## Розділ 3. Визначення користувачів системи

**3.1. Ролі та функціональне призначення**
Для забезпечення розмежування доступу та відповідальності в системі визначено три основні ролі користувачів:

| Роль (Клас) | Рівень доступу | Функції та відповідальність |
| :--- | :--- | :--- |
| **Читач (Reader)** | Базовий | Реєстрація, авторизація, пошук у каталозі та онлайн-резервування книг для власного користування. |
| **Бібліотекар (Librarian)** | Операційний | Управління книжковим фондом, реєстрація видачі та повернення книг, контроль фізичного стану примірників. |
| **Адміністратор (Admin)** | Системний | Керування обліковими записами, моніторинг роботи сервісів нагадувань, перегляд аналітики та графіків обігу. |

**3.2. Доступ до функцій за ролями**
* **Читач**: має доступ до сторінок каталогу та особистого кабінету. Обмежений у можливості редагування інформації про книги.
* **Бібліотекар**: має доступ до інтерфейсу керування обігом. Може змінювати статус примірника (наприклад, з "Available" на "Issued").
* **Адміністратор**: має повний доступ до всіх модулів системи, включаючи технічні налаштування та статистичні звіти.

**3.3. Обмеження безпеки та права доступу**
* **Автентифікація**: доступ до персоналізованих функцій надається лише після успішного входу в систему з використанням JWT-токенів.
* **Контроль доступу (RBAC)**: права доступу до конкретних маршрутів API перевіряються на рівні сервера. Якщо роль користувача не відповідає необхідному рівню, система блокує запит.
* **Ізоляція даних**: користувачі ролі "Читач" можуть бачити та редагувати лише власні дані про резервування. Прямий доступ до таблиць бази даних закритий для всіх клієнтських ролей.
